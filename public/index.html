04 / GOOD TO KNOW

A few things,
made clear.

Questions about the platform? Start here.

What is PALL × KAII?＋

PALL × KAII is a platform in development for managing OTP services and API integrations.

Can I create an account or place orders today?＋

Account registration and sign-in are available when the database is configured. Email verification, deposits, and order placement are still in development.

Is the developer API available?＋

A limited read-only customer API is available when the database is configured. The provider integration and order operations are still being developed and verified.

Where can I check the system status?＋

The status section below reports the application and database check separately. Provider connectivity is not currently checked.
