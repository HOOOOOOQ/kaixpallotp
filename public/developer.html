DEVELOPER PLATFORM / V1

Build with clarity.

The PALL × KAII customer API provides scoped, read-only access to account and wallet data. Order creation and webhooks are not available.

Create an API key ↗
01 / AUTHENTICATION

Keep your keys private.

Create a key in your workspace and choose only the scopes you need. The secret appears once. Send it using the Bearer authorization header over HTTPS, never in browser code or a public repository. Revoke compromised keys immediately.

cURL / BALANCE
curl -H "Authorization: Bearer $PALL_API_KEY" \\
  https://YOUR_HOST/api/v1/balance

02 / ENDPOINTS

Small surface. Clear scope.

METHODPATHREQUIRED SCOPEDESCRIPTION
GET/api/v1/accountaccount.readAccount identity and status
GET/api/v1/balancebalance.readAvailable and reserved balances
GET/api/v1/transactionstransactions.readLatest 50 ledger entries

Amounts ending in _minor are integer strings. The API currently returns at most 50 transactions; pagination and monetary write operations are not implemented. Rate limit: 60 authorized requests per key per minute.

03 / RESPONSES

Designed for predictable handling.

401 / 403

An invalid or revoked key returns 401. A valid key without the required scope returns 403.

429

The per-key limit has been reached. Respect the Retry-After header before retrying.

503

The service or database is unavailable. Never infer a successful operation from an error.

This API is under development and has not been verified against a real MariaDB deployment. Do not use it for production or real funds.
